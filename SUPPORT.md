# Support

This policy applies to all repositories in the Niobe Labs organization.

## Asking a question

Open an issue in the relevant repository. There's no dedicated Q&A forum —
issues are the single place questions, bugs, and feature requests are
tracked.

## Filing a bug or requesting a feature

Use the repository's issue templates (bug report / feature request). They
prompt for the information needed to act on the report quickly.

## Reporting a security issue

Do not use a public issue. See [SECURITY.md](SECURITY.md) for private
reporting channels.

## Contributing a fix

See [CONTRIBUTING.md](CONTRIBUTING.md) for the development workflow.
